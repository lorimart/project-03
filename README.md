### Project Overview

The Mana Potion Lounge is a fictional gaming-themed cafe and esports lounge designed to attract local gamers and build a strong tabletop and console community. 

This repository contains a fully responsive, two-page static website prototype built using semantic HTML5 and a single, custom external CSS3 stylesheet. The project strictly adheres to a "Gamer Noir" design system—utilizing a dark-mode palette paired with vibrant neon blue and neon red accents to match the branding of the lounge. 

### Repository Structure & Deliverables

The project files are organized cleanly within this repository to meet all submission expectations: 

* **Root Directory** 

  * index.html - The primary homepage layout featuring the hero banner and core amenities grid.
  * about.html - The secondary page highlighting the business origins, operational hours, and a contact/reservation mockup form.
  * style.css - The single, external stylesheet governing layout, responsive typography, and consistent visual styling for both web pages.
* **Documentation (docs/)** 

  * [docs/scope.md](./docs/final-project-scope.md) - The Project Scope Statement defining boundaries and project exclusions.
  * [docs/plan.md](./docs/plan.md) - The Work Breakdown Structure (WBS) schedule and TAME risk analysis framework.
  * [docs/retrospective.md](./docs/retrospective.md) - A post-project reflection analyzing process efficiency.
